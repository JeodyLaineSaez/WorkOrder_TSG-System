Import Work Orders from CSV

CSV Import Instructions

Please ensure your CSV file contains the following columns:

  • campus - Campus name (will be created if doesn't exist)
  • office - Office name (will be created if doesn't exist)
  • type - Work order type (desktop_laptop, printer, scanner, lan_internet, other)
  • item - Item description (required)
  • serial_number - Serial number (optional)
  • issue_description - Issue description (required)
  • requested_by - Requester name (optional, defaults to current user)
  • date_requested - Date requested (multiple formats supported)
  • assigned_technician - Technician name (optional)
  • category - Category (repair, maintenance, checkup, etc.)
  • remarks - Remarks (optional)
  • date_completed - Date completed (multiple formats supported, optional)
  • status - Status (pending, on_going, completed)

Note: Campuses and offices will be automatically created if they don't exist. Users and technicians will be automatically created if they don't exist. Duplicate prevention ensures only one entry per unique name. Empty fields will be preserved as empty.

Date Format Support

The system supports various date formats:

  • Standard: 2024-01-15 09:30:00, 2024-01-15 09:30, 2024-01-15
  • US Format: 01/15/2024 09:30:00, 01/15/2024 09:30, 01/15/2024
  • European Format: 15/01/2024 09:30:00, 15/01/2024 09:30, 15/01/2024
  • Text Format: January 15, 2024 09:30:00, January 15, 2024
  • AM/PM Format: July 21, 2025 at 08:00 AM, July 21, 2025 at 03:20 PM
Duplicate Prevention

The system prevents duplicate entries:

  • Users: Exact name matching prevents multiple users with same name
  • Technicians: Exact name matching prevents multiple technicians with same name
  • Campus/Office: Exact name matching prevents duplicate locations
  • Case Insensitive: "John Doe" and "john doe" are treated as the same person
